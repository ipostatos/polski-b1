# Источники

Все материалы — официальные, Państwowej Komisji ds. Poświadczania Znajomości Języka
Polskiego jako Obcego.

## Правовая рамка репозитория

В репозитории **не лежат** ни аркуши, ни аудио, ни транскрипции. Это чужие авторские
материалы, и их републикация не наша. Они скачиваются локально скриптом и попадают
в `archive/`, который закрыт `.gitignore`.

Исключение — нормативные акты: они не являются предметом авторского права (ustawa
o prawie autorskim, art. 4), поэтому инвентарь требований B1 цитируется в
`docs/GRAMATYKA_B1.md` открыто.

В репозиторий едут только **наши** материалы: разборы, статистика, сгенерированные
упражнения, код бота, рабочая тетрадь.

## Как получить материалы

```bash
bash tools/fetch_archive.sh     # 45 файлов, ~900 МБ → archive/
python tools/extract_text.py    # → archive_text/
python tools/mine_tasks.py      # → data/exam_map.json
```

### Нормативка

* **Rozporządzenie Ministra Nauki i Szkolnictwa Wyższego z 14.02.2025 w sprawie
  egzaminów z języka polskiego jako obcego — Dz.U. 2025 poz. 217.** Действует
  с 22.02.2025; это юридическая база экзамена 17.10.2026: структура, пороги,
  стандарты требований.
* Rozporządzenie MNiSW z 26.02.2016, Dz.U. 2016 poz. 405 — **утратило силу
  02.01.2025**. Исторический источник: по нему собран инвентарь B1
  в `docs/GRAMATYKA_B1.md` (содержательно актуален, сверен с новым актом)
  и по нему проводились архивные сессии 2021–2024.
* Реформа орфографии с 01.01.2026: переходный период на экзаменах —
  в 2026–2030 принимаются и прежние, и новые написания; только новые —
  с 2031 года. Подробнее — `docs/EXAM_SPEC.md`, § 9.
* Актуальная структура экзамена B1 (dorośli): страница экзамена на
  certyfikatpolski.pl — тайминг 25/45/45/75 (razem 190 минут) + mówienie до 15.
