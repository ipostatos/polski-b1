# Источники

Все материалы — официальные, Państwowej Komisji ds. Poświadczania Znajomości Języka
Polskiego jako Obcego.

## Правовая рамка репозитория

В репозитории **не лежат** ни аркуши, ни аудио, ни транскрипции. Это чужие авторские
материалы, и их републикация не наша. Они скачиваются локально скриптом и попадают
в `archive/`, который закрыт `.gitignore`.

Исключение — **Rozporządzenie MNiSW z 26.02.2016 (Dz.U. 2016 poz. 405)**: акты
нормативные не являются предметом авторского права (ustawa o prawie autorskim, art. 4),
поэтому инвентарь требований B1 цитируется в `docs/GRAMATYKA_B1.md` открыто.

В репозиторий едут только **наши** материалы: разборы, статистика, сгенерированные
упражнения, код бота, рабочая тетрадь.

## Как получить материалы

```bash
bash tools/fetch_archive.sh     # 45 файлов, ~900 МБ → archive/
python tools/extract_text.py    # → archive_text/
python tools/mine_tasks.py      # → data/exam_map.json
```
