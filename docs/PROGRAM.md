### Недели 2–3 (24.08–06.09) — ГРАММАТИКА, ударная фаза

25–30 минут в день, по приоритету из `docs/EXAM_SPEC.md` § 4:

1. **Задание I** — склонение существительных, прилагательных, местоимений (5 б.)
2. **Задание VII** — вид и наклонения (5 б.)
3. **Задание IV** — времена (5 б.)
4. **Задание VI** — трансформации (5 б.)

Эти четыре = 20 из 30 баллов. Порог модуля берётся уже на них.
Мелочь (союзы, степени, вопросы, предлоги) — вторым слоем, недели 4–5.

Учим не таблицы, а **управление**: szukam czego, potrzebuję czego, interesuję się czym,
rozmawiam z kim, myślę o czym, czekam na kogo/co. Список глагольного управления,
ограниченный инвентарём B1, — `data/rekcja.json`; функции падежей —
`docs/GRAMATYKA_B1.md`, § 3.1.

### Недели 2–8 — СЛУШАНИЕ, ежедневно 15–20 минут

Два режима, чередуются:

**Режим A — Exam listening.** Берём задание из архива.
Первое прослушивание — только ответы. Проверка. Второе — где именно потерялась
информация. Потом официальная транскрипция, незнакомые конструкции → в словарь ошибок.

**Режим B — Задание I, один проход.** Отдельная тренировка на 14 микровысказываний,
которые звучат ровно один раз. Это 7 баллов из 30, самый дорогой кусок модуля.
Тренируется на интенциях: просьба / согласие / отказ / одобрение / критика / безразличие /
поздравление / приглашение.

**Shadowing** — 30–60 секунд из транскрипции, повтор вслух за диктором.
Одновременно słuchanie + wymowa + mówienie.

### Недели 2–8 — ЧТЕНИЕ, ежедневно 15–20 минут

Не переводить текст. Три режима:

* **Skimming** — о чём текст (задание IV, подбор заголовков);
* **Scanning** — где конкретная информация (задание II, TAK/NIE/BI);
* **Стыки** — задание III, подбор изъятых фрагментов: смотреть на местоимения,
  союзы и согласование на границе, а не на смысл абзаца.

Правило для TAK/NIE/BRAK INFORMACJI: TAK — следует из текста (перефраз тоже считается),
NIE — текст противоречит, BI — текст не позволяет ни подтвердить, ни опровергнуть.
Не додумываем из общих знаний, но и не требуем буквального совпадения слов.

### Недели 3–8 — ПИСЬМО, 3 работы в неделю

Пишешь сам, без переводчика и без ИИ. Я возвращаю разбор в формате:

```
❌ W zeszłym tygodniu ja był w Gdańsku.
✅ W zeszłym tygodniu byłem w Gdańsku.
   CASE: czas przeszły + rodzaj męski, zaimek "ja" zbędny
```

Ошибка, повторившаяся третий раз, уходит в Error Map и увеличивает долю упражнений
на свою категорию.

Каждая работа — **комплект целиком**: короткая (30–35 слов) + длинная (165–170).
Раздельно тренировать бессмысленно: на экзамене они оцениваются вместе.

Отдельно тренируем **чувство объёма**: 30 слов и 170 слов на глаз, без подсчёта.
Это 2 балла из 30 модуля, которые даются даром (допуск ±10% в боте — наша
тренировочная эвристика, официального процента не объявлено).

Шаблоны жанров — `data/szablony.json` (раздел pisanie), печатная версия — в тетради.

### Недели 3–8 — ГОВОРЕНИЕ, ежедневно 10–15 минут

Три каркаса под три задания экзамена:

**Opis ilustracji.** Не «Widzę kobietę. Jest park. Jest pies», а
«Na zdjęciu widzę kobietę, która prawdopodobnie spędza wolny czas w parku.
Wydaje mi się, że...». Каркас: что вижу → кто → где → что происходит → предположение → вывод.

**Monolog.** Najpierw → następnie → później → w końcu.

**Sytuacja komunikacyjna.** Роль → цель → просьба/предложение → реакция на возражение → договорённость.

Для мнения: TEZA → ARGUMENT → PRZYKŁAD → KONTRARGUMENT → WNIOSEK.
Moim zdaniem... Przede wszystkim... Na przykład... Z drugiej strony... Dlatego uważam, że...

Каркас позволяет говорить даже на неприятной или неожиданной теме.

## Error Database

Каждая существенная ошибка получает категорию:

| Код | Что это |
|---|---|
| `CASE-GEN` | dopełniacz |
| `CASE-DAT` | celownik |
| `CASE-ACC` | biernik |
| `CASE-INS` | narzędnik |
| `CASE-LOC` | miejscownik |
| `ASP` | aspekt |
| `TENSE` | czasy |
| `MOOD` | tryby (rozkazujący, przypuszczający) |
| `PREP` | przyimki |
| `REKCJA` | управление глагола |
| `CONJ` | spójniki |
| `COMP` | stopniowanie |
| `NUM` | liczebniki |
| `WO` | szyk zdania |
| `LEX` | leksyka |
| `ORTH` | ortografia i interpunkcja |
| `REG` | rejestr / styl |
| `TASK` | невыполнение условия задания (форма, объём) |

Формат записи:

```
#ASP-004
❌ Wczoraj robiłem to zadanie i skończyłem.
✅ Wczoraj zrobiłem to zadanie.
   Выбор вида: результат одного завершённого действия → dokonany.
```

Категория, которая начинает повторяться, автоматически получает больше упражнений.
Это эффективнее, чем «давай ещё падежи».

База ведётся ботом в `moje/postep.db` (SQLite, не коммитится); просмотр — /mapa.
