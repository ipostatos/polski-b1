# Polski B1 — подготовка к государственному экзамену

Персональная система подготовки к **państwowy egzamin certyfikatowy z języka polskiego
jako obcego, poziom B1 (dorośli)**. Дата экзамена: **17.10.2026**.

Подход обратный учебнику: не «глава 1 → глава 20», а
**реальные экзамены → повторяющиеся навыки → точечная грамматика → симуляции**.

## Чем это отличается от курса польского

Разобраны машинно все 15 официальных сессий B1 за 2021–2024. Выяснилось, что экзамен
гораздо предсказуемее, чем кажется:

* **модуль грамматики не менялся с 2021 года**: те же 8 заданий, в том же порядке,
  с теми же баллами. Меняется только текст;
* четыре задания из восьми дают **20 баллов из 30** — порог модуля берётся на них;
* **задание I в аудировании звучит один раз**, остальные четыре — дважды. Это 7 баллов
  из 30 на одном проходе, и это отдельный навык;
* модуль чтения — тоже жёсткий скелет из 5 форматов;
* в письме **объём — это балл**, который даётся даром за попадание в 30 и 170 слов.

Подробности с цифрами — [`docs/EXAM_SPEC.md`](docs/EXAM_SPEC.md).

## Состав

```
docs/        спецификация экзамена и программа
tools/       выкачка архива, извлечение текста, разбор заданий
data/        разобранная карта экзаменов, инвентари, упражнения
workbook/    генератор рабочей тетради в PDF
bot/         телеграм-бот и Mini App
klucze/      реконструированные ключи к мокам (помечены как реконструкция)
```

Официальные материалы (аркуши, mp3, транскрипции) **в репозиторий не входят** —
скачиваются локально:

```bash
bash tools/fetch_archive.sh     # 45 файлов, ~900 МБ
python tools/extract_text.py
python tools/mine_tasks.py
```

## Порог

Юридически достаточно 50% в каждом из пяти модулей. Готовимся не к 50%, а к запасу:
один неудачный текст или одна запись не должны решать исход.

| Модуль | Порог | Цель |
|---|---|---|
| Rozumienie ze słuchu | 15/30 | 22/30 |
| Rozumienie tekstów | 15/30 | 23/30 |
| Poprawność gramatyczna | 15/30 | 22/30 |
| Pisanie | 15/30 | 21/30 |
| Mówienie | 20/40 | 28/40 |
